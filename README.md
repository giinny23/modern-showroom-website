# Modern Showroom 

A modern car showroom website developed as a university web development project using **HTML and CSS**.

The website showcases a selection of vehicles, their details, and showroom information through a clean and user-friendly interface.

## Features
- Home page with featured vehicles and reviews
- About page
- Vehicle listings and details
- Image gallery
- Contact form
- Photoshop before-and-after gallery

## Technologies
- HTML5
- CSS3
- Adobe Photoshop

## Getting Started

Clone the repository and open `index.html` in your browser to view the website.
